# DEMO 09: Dynamic HLS Live Server

A high-performance, multi-threaded continuous live TV broadcast server implementing Live Streaming (HLS, RFC 8216) built on top of **GHttpsServerIOCP** (Delphi IOCP HTTP/HTTPS/WebSocket/HTTP3).



---

## Key Features & Architecture

1. **Native Delphi MPEG-TS In-RAM Live Engine**:
   - The Delphi broadcast engine (`TDynamicHlsLiveEngine`) directly loads the source broadcast stream (`stream_live.ts`) into RAM.
   - Parses 188-byte MPEG-TS packets and SPS/IDR keyframe boundaries in 100% pure Pascal without any external tools.
   - High-throughput in-memory serving of `/live/segment_X.ts` with zero disk I/O overhead.
   - Dynamic sliding window live manifest generation (`5 segments window`) at `/live/stream.m3u8`.
   - Real-time continuous timeline synchronization (PCR/PTS/DTS offsetting) computed on-the-fly in Delphi memory.

2. **Independent WebSocket Telemetry (`/status-ws`)**:
   - A dedicated real-time WebSocket channel emitting JSON frames every second containing station uptime (`uptime_sec`) and active viewer count (`active_viewers`).
   - Complete isolation: WebSocket disconnections or stalls do not affect HLS video playback.

## Getting Started

### 1. Build and Run the Server in Delphi:
1. Open the project `DEMO\09_MoveServer\D09_MoveServer.dpr` in RAD Studio / Delphi (Win64 Debug or Release).
2. Compile and build the project.
3. Ensure the `www/` subfolder and `stream_live.ts` file are present in the executable directory (generated by `FILM/fajerwerki.py`).
4. Launch `D09_MoveServer.exe`.

### 2. Browser Playback:
* Open `https://localhost:8089/` in your browser.
* The live broadcast will start automatically. Control playback using the dedicated **Start** and **Pause** buttons.

### 3. VLC Media Player Playback:
   Enter the live stream URL:
   ```text
   https://localhost:8089/live/stream.m3u8
   ```
